🛡 Cyber Security Toolkit Pro

A browser-based collection of cybersecurity utilities built for a cybersecurity course certificate project. Covers password security, hashing, encoding, and network/web reconnaissance tools, in a dark neon-cyber themed interface.

Structure

  • index.html — homepage
  • css/ — stylesheets (base theme, shared theme tokens, animations, responsive rules)
  • js/ — shared scripts (navigation, search, theme toggle, shared tool helpers)
  • pages/ — individual tool pages

Tools included

  • Password Generator
  • Password Strength Checker
  • Hash Generator / Hash Checker
  • Base64 Encoder/Decoder
  • JSON Formatter
  • JWT Decoder
  • QR Code Generator
  • IP Lookup / DNS Lookup / WHOIS Lookup / SSL Checker

Running locally

From the project root, run:

python -m http.server 5500

Then open http://localhost:5500 in your browser.

Notes

This project is for educational and defensive security purposes, built as part of a cybersecurity course. Network-lookup tools (WHOIS, DNS, IP, SSL) rely on third-party public APIs since browsers cannot make raw network queries directly.
